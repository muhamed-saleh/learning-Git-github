# Git & GitHub Test Project

This is a simple HTML and CSS project created for practicing Git and GitHub.  
The goal is not the code itself, but to use it as a sample project for learning repository management, version control, and collaboration.

---

## Files

- **git-github-test.html**  
  A minimal HTML file with some inline CSS.  
  It displays a test page styled with basic colors and text.

---

## Purpose

- Practice creating and tracking changes in a local Git repository.
- Commit and push code to a remote GitHub repository.
- Learn how to manage branches, commits, and remotes with a real project file.
